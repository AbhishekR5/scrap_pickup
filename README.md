# EcoScrap — Doorstep Scrap Pickup Platform

EcoScrap is a modern, high-converting, mobile-first responsive web application for doorstep scrap collection with transparent digital weighing, live market rates, and instant UPI/cash payouts.

## ✨ Features

- 📱 **True Responsive Design**: Fluid layout tested across Desktop (1920x1080 to 1280x720), Tablet (iPad portrait & landscape), and Mobile (320px to 430px).
- ⚡ **Interactive Rate Estimator**: Live dynamic scrap rate calculator with real-time payout estimations.
- 📋 **Live Scrap Price List**: Daily updated rates table with real-time search and filter tabs.
- 📅 **3-Step Booking Wizard**: Seamless doorstep pickup scheduling with category selection, date/slot picker, and instant booking reference modal (`#ES-XXXXX`).
- 💬 **WhatsApp Integration**: Instant deep links to chat and confirm pickups directly with the booking desk.
- 🌿 **Sustainability Impact Counters**: Real-time stats on trees saved, water conserved, and carbon emissions avoided.
- 🏢 **B2B & Commercial Section**: Enterprise scrap management, GST billing, and green recycling certificates.
- ♿ **Accessibility & Performance**: 44px+ touch targets, keyboard navigation, and reduced motion support.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve it locally:

```bash
# Using Python
python -m http.server 8080

# Using Node / npx
npx serve .
```

## 🛠️ Tech Stack

- **HTML5**: Semantic, accessible markup with OpenGraph & meta tags.
- **CSS3**: Fluid typography (`clamp()`), CSS Grid, Flexbox, custom properties / design tokens.
- **JavaScript (ES6+)**: Modular vanilla JS for interactive components, slider, drawer, and booking wizard.
